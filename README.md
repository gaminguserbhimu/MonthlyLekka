# Monthly Expenses - Personal & Event Expense Tracker

Monthly Expenses is a modern, privacy-focused Android application designed to track personal and event-based expenses, manage budgets, and analyze spending habits.

## Features

- 📊 **Expense Tracking & Analytics:** Categorize expenses, view summaries, and analyze spending patterns with interactive charts.
- 🎯 **Event Expense Management:** Create separate budget tables ("Lekkas") for events, trips, or specific monthly targets.
- 🔐 **Privacy First:** All financial records, receipt photos, and notes are saved locally on your device.
- 🧾 **Receipt Attachments:** Attach photos of receipts to transactions.
- 🎨 **Modern Material 3 Design:** Fully responsive, edge-to-edge UI built with Jetpack Compose.

## Tech Stack

- **Language:** Kotlin
- **UI Toolkit:** Jetpack Compose (Material 3)
- **Architecture:** MVVM, Clean Architecture
- **Database:** Room Database (Local Persistence)
- **Async Processing:** Kotlin Coroutines & Flow
